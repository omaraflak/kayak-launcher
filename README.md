# Kayak Launcher

The Mac app that installs, runs and updates [Kayak](https://github.com/omaraflak/kayak),
and opens it in your browser.

**Get it:** install [Docker Desktop](https://www.docker.com/products/docker-desktop/),
then download the [latest release](https://github.com/omaraflak/kayak-launcher/releases/latest)
and open it. The first time, macOS blocks it: go to **System Settings → Privacy &
Security** and click **Open Anyway**.

**From source:** `npm install && npm run tauri dev`
